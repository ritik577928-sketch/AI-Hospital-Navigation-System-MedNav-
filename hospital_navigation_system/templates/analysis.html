03 — HEURISTIC FUNCTION
Heuristic Values h(n)
Static heuristic estimates used by A* and GBFS. h(n) represents the estimated distance from node n to a critical care destination. Lower value = closer to priority care.
HEURISTIC FUNCTION DEFINITION
h(n) = estimated cost from node n to goal
Used by A*: f(n) = g(n) + h(n)
Used by GBFS: f(n) = h(n) only

Our heuristic is admissible — it never overestimates the true cost, guaranteeing A* finds the optimal path.

Algorithm 8 — Naïve Bayes Theorem
Probabilistic department prediction based on patient symptoms
Bayesian Probability Theory

Naïve Bayes applies Bayes' theorem with the conditional independence assumption: each symptom contributes independently to the posterior probability of each department.

P(dept | e₁,e₂,...,eₙ)
  ∝ P(dept) × P(e₁|dept) × P(e₂|dept) × ... × P(eₙ|dept)

Where:
P(dept) = prior (visit frequency)
P(eᵢ|dept) = likelihood (symptom given dept)
Laplace smoothing α=1 prevents zero probabilities
Key Properties
▸ Computationally O(d×k) — d features, k departments
▸ Works well with small datasets — no training needed
▸ Log-space computation prevents floating-point underflow
▸ Softmax converts log-scores to display probabilities
▸ Top prediction auto-fills navigation goal
